# TFM-Mercado-El-ctrico

Autor/a: Ángela Vázquez Guerra

Titulación: Máster en Big Data y Ciencia de datos 

Este repositorio sirve como anexo al Trabajo Fin de Máster (TFM) y contiene los fragmentos de código de programación desarrollados para el proyecto, así como el documento original del cuadro de mandos. En concreto, se incluyen:

· Consultas en lenguaje M: Código utilizado en Power Query para los procesos de extracción, transformación y carga (ETL) desde la API de ESIOS.

· Medidas DAX: Fórmulas analíticas principales diseñadas para la capa de cálculo y la creación de los indicadores del cuadro de mandos interactivo en Power BI.

· Archivo de Power BI (.pbix): Documento original con el cuadro de mandos interactivo completo, que permite al tribunal visualizar la integración de los datos, probar los filtros temporales y comprobar el funcionamiento práctico de la solución analítica propuesta.
